BÀI TẬP CHƯƠNG CSS / CSS3

Danh sách 5 bài tập thực hành Thiết kế Web

  • Bài 1: Các kiểu định dạng khung viền (Bài 2.1.5) Sử dụng 3 thẻ <div> lồng nhau với border, border-radius và padding
  • Bài 2: Định dạng hỗn hợp (Bài 2.1.6) Sử dụng thẻ <span>, class CSS và liên kết file CSS ngoài
  • Bài 3: Thiết kế Menu ngang một cấp (Bài 2.3.1) Sử dụng danh sách <ul> <li> kết hợp thuộc tính float và :hover
  • Bài 4: Thiết kế Menu ngang hai cấp (Bài 2.3.2) Menu đa cấp xổ xuống khi di chuột (position: absolute/relative)
  • Bài 5: Tạo chữ Drop Cap & Chia cột báo (Bài 2.4.1 & 2.4.2) Sử dụng pseudo-element :first-letter và thuộc tính column-count
